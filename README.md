# claude_wipe_convos

Delete Claude Code conversation data only. Asks first; never touches credentials, settings, plugins, skills or memory.

## Requirements

None (bash).

## Use

```
chmod +x claude-wipe-convos.sh
./claude-wipe-convos.sh
```

Made for Debian. Run it from its folder or put it on your `PATH`. Run it with `-h` where supported, or read the comment header at the top of the script.
